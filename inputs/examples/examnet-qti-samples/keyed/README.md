# Exam.net QTI Samples

Deterministic QTI 2.1 sample packages generated by:

```bash
pdm run examnet-qti-samples
```

Each sample directory contains:

- `qti-package.zip`
- `qti-validation-report.json`

The reports are the authority for package SHA-256, local package/XML preflight,
official 1EdTech validator dependency status, optional QTIWorks smoke status,
and Exam.net import-proof status.

Matching is proof-gated and remains `examnet_proof_status: not_proven` until a
live Exam.net import proof is captured.
